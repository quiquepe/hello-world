Cómo obtener los comentarios:
1. Abrí el posteo en Instagram (web o app)
2. Seleccioná y copiá todos los comentarios
3. Pegalos abajo. El sistema detecta los @usuarios automáticamente
Instagram Graph API
Necesitás un Access Token de la Graph API de Instagram/Facebook para cargar comentarios automáticamente desde un posteo.

Podés obtener uno en developers.facebook.com creando una app con permisos de Instagram.

Podés obtener el Media ID usando el endpoint /ig_hashtag_search o desde tu dashboard de Facebook.
